🚀 CareerCraft AI
Your AI-Powered Career Assistant

CareerCraft AI is a full-stack AI platform that helps job seekers analyze resumes, understand job descriptions, match their skills to opportunities, tailor resumes, prepare for interviews, and track applications — all in one place.

✨ Features

📄 Resume Analysis
Upload and analyze your resume to understand your skills and experience.

🎯 Resume–Job Matching
Compare your resume with a job description and identify how well you match.

✍️ AI Resume Tailoring
Generate job-specific resume improvements based on the target role.

💼 Job Description Analysis
Extract important skills, requirements, and responsibilities from job descriptions.

🎤 Interview Preparation
Prepare for interviews with AI-assisted questions and practice workflows.

📋 Application Tracking
Keep your job applications organized and track their progress.

🔐 Authentication
Secure user authentication and protected application routes.

⚙️ Getting Started
1. Clone the repository
git clone https://github.com/ayanangshugoswamiabir-collab/CareerCraft-AI.git
cd CareerCraft-AI
2. Setup Backend
cd backend
npm install

Create your environment file:

Copy-Item .env.example .env

Add your required API keys, database URL, and other environment variables to .env.

Start the backend:

npm run dev
3. Setup Frontend

Open a new terminal:

cd frontend
npm install
npm run dev

Open the local URL provided by Vite.

🔐 Environment Variables

Your .env file contains sensitive information and should never be committed to GitHub.

Use:

backend/.env.example

as the template for your local configuration.

🎯 Project Goal

The goal of CareerCraft AI is simple:

Make the entire job-search process smarter, faster, and more personalized with AI.

Instead of using separate tools for resumes, job matching, interview preparation, and application tracking, CareerCraft AI brings these workflows together into one platform.
